# Spread Joy Collective

A simple static website: plain HTML and one stylesheet (`style.css`). No build step.

- Edit the text directly in each `.html` file.
- To publish with GitHub Pages: repo Settings > Pages > deploy from the `main` branch, root folder.
- Images are currently loaded from Squarespace's image servers. Download them into an `images/` folder and update the `src` links to make the site fully self-contained.
